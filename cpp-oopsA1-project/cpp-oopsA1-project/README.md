# C++ OOPs A1 Project

## Overview
The C++ OOPs A1 Project is a demonstration of various programming concepts in C++. The main program, located in `src/oopsA1.cpp`, showcases input/output operations, arithmetic operations, temperature conversion, assignment operators, value swapping using bitwise operators, and conditional statements. This project serves as an educational tool for understanding fundamental programming concepts in C++.

## Features
- Input and output of integers, decimals, and characters.
- Basic arithmetic operations (addition, subtraction, multiplication, division).
- Temperature conversion from Celsius to Fahrenheit.
- Use of assignment operators (`+=`, `-=`).
- Swapping of two values using bitwise operators.
- Calculation of library fines based on late days.
- Arithmetic operations using switch-case statements.
- Even or odd number determination using if-else and conditional statements.

## Building and Running the Program

### Prerequisites
- A C++ compiler (e.g., g++, clang++).
- A terminal or command prompt.

### Instructions
1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd cpp-oopsA1-project
   ```
3. Compile the program:
   ```
   g++ src/oopsA1.cpp -o oopsA1
   ```
4. Run the program:
   ```
   ./oopsA1
   ```
